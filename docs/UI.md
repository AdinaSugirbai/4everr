# Career Studio UI нұсқасы

## Іске қосу

Node.js 20.9+ қажет. Репозиторий түбірінде:

```bash
npm ci
npm run dev
```

Басты бет: `/`. Осы аптаның үш негізгі UI беті: `/dashboard` (кабинет және әрекеттер тарихы), `/posts/new` (жасау), `/posts/demo-frontend` (көру, `?edit=1` арқылы өңдеу).

Қосымша UI жолдары: `/careers`, `/quiz-interests`, `/roadmap/frontend`, `/tests`, `/tests/html`, `/stats`, `/jobs`, `/employer`.

## Дайын UI мүмкіндіктері

- Қазақ тіліндегі адаптивті интерфейс, қою фон және күлгін/лайм акценттері.
- Авторлық CSS иллюстрациясы, қозғалыстағы карта, карточка/батырма/бет ауысу анимациялары. `prefers-reduced-motion` ескеріледі.
- Пост жасау, жоба ретінде сақтау, өңдеу, әрекеттер тарихын іздеу және сүзу.
- Вакансиялар сүзгілері URL параметрлерінде сақталады.
- 12 сұрақтық үлгі сауалнама; төрт тақырып бойынша қысқа демо тесттер және браузерлік статистика.

## Шектеулер

Бұл — UI кезеңі, толық өндірістік платформа емес. Аккаунттар, серверлік рөлдер, Prisma/PostgreSQL, нақты модерация және өтінімдер қосылмаған. Посттар мен нәтижелер тек осы браузердің `localStorage` ішінде сақталады. Демо сауалнама салмақтары, компаниялар және жалақылар үлгі ретінде берілген. Демо тест: 3 сұрақ, 3 минут, клиенттік тексеру; ол нақты серверлік әділ тестті алмастырмайды. Метрикадағы бағандар декоративті.

## Тексеру

```bash
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm test
```

`npm test` өндірістік жинақтан серверді 3100 портында уақытша көтереді; алдымен `npm run build` орындаңыз. Linux cloud ортада жүйелік Chromium қолдану үшін `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test`.

Қолданба UI-і сыртқы шрифт, құпия кілт немесе дерекқор талап етпейді. Webpack + PostCSS қолданылған: осы cloud ортада Turbopack-тың ішкі порт ашуына шектеу бар.

Төрт қатысушыға тапсырма бөлу: [TEAM_TASKS.md](./TEAM_TASKS.md).
