# Төрт адамға арналған дайын Next.js ZIP бөліктері

Бұл тармақ тек архивтерді GitHub арқылы жүктеп алуға арналған. **Осы handoff тармағын dev не main-ге merge жасамаңыз.** Әр адам өз архивіндегі кодты өзінің feature тармағынан commit жасап енгізеді.

GitHub аккаунтына кіру қажет болуы мүмкін. Егер файл беті ашылса, **Download raw file** батырмасын басыңыз.

Толық нұсқаулық: [START_HERE.md](START_HERE.md). Әр ZIP ішінде `READ_ME_FIRST.md`, `FILES.txt` және тек сол адамға тиесілі бастапқы код бар `files/` папкасы орналасқан. `files/` ішін репозиторий түбіріне көшіріңіз; папканың өзін көшірмеңіз.

Реті: бірінші қатысушы → PR-ды dev-ке біріктіру → екінші қатысушы жаңартылған dev-ті алу → үшінші → төртінші. Бастапқы толық `feature/career-studio-ui` тармағын dev-ке merge жасамаңыз.

Архивтер Next.js + TypeScript + Tailwind жобасының бөліктері, `index.html` файлы жоқ. Төрт кезеңнің әрқайсысында lint, TypeScript және build тексерілген; толық жинақта үш Playwright UI тесті өткен.
