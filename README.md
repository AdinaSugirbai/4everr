## Техникалық тапсырма

### 1. Жоба туралы

| Параметр | Мазмұны |
|---|---|
| **Атауы** | 4everr |
| **Түрі** | Көп беттік веб-сайт (Next.js) |
| **Мақсаты** | Адамдарға өмірдегі маңызды естеліктерді (сурет, оқиға, күн) бір жерде әдемі түрде сақтап, көрсетуге мүмкіндік беретін «цифрлық естелік альбомы» сайтын жасау |
| **Идея** | «4everr» («forever») атауы естеліктердің мәңгі сақталуын білдіреді |
| **Мақсатты аудитория** | Студенттер, достар тобы, отбасылар, өз сәттерін жинағысы келетін кез келген адам |
| **Команда** | 4 адам |
| **Оқу мақсаты** | Git/GitHub арқылы командалық жұмысты, Pull Request процесін және Next.js негіздерін үйрену |

### 2. Жобаның міндеттері
1. GitHub-та репозиторий ашып, `main` және `dev` тармақтарын құру.
2. `npx create-next-app@latest` арқылы Next.js жобасын орнату.
3. Сайттың негізгі беттерін жасау және оларды өзара байланыстыру.
4. README-де командалардың мәнін, жоба құрылымын және ТЗ-ны сипаттау.
5. Барлық өзгерісті Pull Request арқылы біріктіру.

### 3. Қолданылатын технологиялар

| Технология | Не үшін |
|---|---|
| Next.js (App Router) | Веб-қосымшаның негізі, беттер арасындағы маршрутизация |
| React | Интерфейс компоненттері |
| TypeScript | Типтелген, қатесі аз код |
| Tailwind CSS | Тез әрі адаптивті дизайн |
| ESLint | Код сапасын тексеру |
| Node.js / npm | Жобаны іске қосу және пакеттерді басқару |
| Git / GitHub | Нұсқаларды бақылау және командалық жұмыс |

### 4. Функционалдық талаптар

| № | Бет / функция | Сипаттамасы |
|---|---|---|
| 1 | **Басты бет** (`/`) | Жоба атауы, қысқа сипаттама, «Естеліктерді көру» батырмасы |
| 2 | **Естеліктер беті** (`/memories`) | Естеліктер карточкаларының тізімі: тақырып, күні, қысқа сипаттама, сурет |
| 3 | **Біз туралы** (`/about`) | Жоба идеясы және команда мүшелері туралы ақпарат |
| 4 | **Байланыс беті** (`/contact`) | Аты, поштасы және хабарлама өрістері бар форма (қарапайым, сервері жоқ) |
| 5 | **Навигация мәзірі** | Барлық бетте көрінетін мәзір, беттер арасында өтуге мүмкіндік береді |
| 6 | **Футер** | Жоба атауы және авторлар |
| 7 | **Адаптивті дизайн** | Сайт телефонда, планшетте және компьютерде дұрыс көрінеді |

### 5. Функционалды емес талаптар
- Жоба `npm run dev` командасымен қатесіз іске қосылады.
- `npm run lint` қателіксіз өтеді.
- `npm run build` сәтті аяқталады.
- Файлдар мен папкалардың аттары түсінікті, бір стильде жазылады.
- Дизайн бірыңғай болады: түстер, қаріптер, батырмалар барлық бетте бірдей.
- Бет жүктелуі тез болады, суреттер артық ауыр болмайды.

### 6. Беттердің құрылымы

```
/            → Басты бет
/memories    → Естеліктер
/about       → Біз туралы
/contact     → Байланыс
```

Әр бет `app/` папкасында өз ішкі папкасында орналасады (мысалы, `app/about/page.tsx`).

### 7. Командалық жұмыс ережелері
- Әр адам өз тармағында жұмыс істейді (`feature/...`).
- `main` тармағына тікелей өзгеріс енгізілмейді.
- Өзгерістер тек **Pull Request** арқылы `dev`-ке, ал дайын нұсқа `dev` → `main` арқылы біріктіріледі.
- Әр PR-ды кемінде бір команда мүшесі қарап шығады.
- Коммит хабарламалары префикспен жазылады:
  - `feat:` жаңа функция
  - `fix:` қатені түзету
  - `docs:` құжаттама
  - `style:` дизайн өзгерісі

- GitHub-та толық командалық жұмыс тарихы бар (коммиттер, тармақтар, Pull Request-тер) репозиторий.
- Орнатылған және `npm run dev` арқылы іске қосылатын Next.js жобасы.

- Төрт беттен тұратын, адаптивті 4everr сайты.
