# 4everr: IT Career Navigator + TechTest

IT-ға қызығатын оқушылар мен студенттерге арналған веб-платформа. Пайдаланушы алдымен өзіне қай IT бағыты сәйкес келетінін біледі, содан кейін сол бағыт бойынша білімін тесттен тексереді.

## Жоба туралы

Екі идея бір жобаға біріктірілді:

- **IT Career Navigator:** IT мамандықтарының каталогы, қызығушылық бойынша мамандық ұсыну, оқу жолының картасы.
- **TechTest:** HTML, CSS, JavaScript, Java бойынша тесттер, таймер, ұпай және нәтижелер статистикасы.

**Қалай жұмыс істейді:**

1. Пайдаланушы қызығушылық сауалнамасынан өтеді.
2. Жүйе бағыт ұсынады (Frontend, Backend, Data Science және т.б.).
3. Пайдаланушы бағыттың оқу жолын және қажетті дағдыларды көреді.
4. Сол дағдылар бойынша тест тапсырады.
5. Нәтиже сақталады, әлсіз тақырыптар көрсетіледі, келесі қадам ұсынылады.

## Мақсаты

- IT мамандығын таңдауға қиналатын адамға нақты бағыт беру.
- Білім деңгейін өлшеуге болатын тест жүйесін жасау.
- Мамандық таңдау мен білім тексеруді бір жерге біріктіру.

## Негізгі функциялар

### 1. IT Career Navigator
- IT мамандықтарының каталогы (Frontend, Backend, Data Science, Mobile, QA, DevOps, UI/UX).
- Әр бағыттың сипаттамасы және қажетті дағдылары.
- Қызығушылық сауалнамасы және мамандық ұсыну.
- Оқу жолының картасы (қадамдар тізбегі).

### 2. TechTest
- HTML, CSS, JavaScript, Java бойынша тесттер.
- Сұрақтардың бірнеше деңгейі (оңай, орташа, қиын).
- Әр тестке таймер.
- Ұпай есептеу.
- Нәтижелер статистикасы (тақырып бойынша пайыз, тапсырылған тесттер тарихы).

### 3. Біріктіру
- Бағыт бетінде сол бағытқа сәйкес тесттерге сілтеме.
- Тест нәтижесіне қарай «қай тақырыпты қайталау керек» кеңесі.

## Технологиялар

| Бөлік | Құрал |
|---|---|
| Фреймворк | Next.js (App Router) |
| Тіл | TypeScript |
| Тексеру | ESLint |
| Деректер (MVP) | JSON файлдар (`data/`) |
| Нәтижелерді сақтау (MVP) | localStorage |
| Хостинг | Vercel |

## Жоба құрылымы

```
4everr/
├── app/
│   ├── page.tsx              # Басты бет
│   ├── careers/              # Мамандықтар каталогы
│   ├── quiz-interests/       # Қызығушылық сауалнамасы
│   ├── roadmap/[slug]/       # Оқу жолының картасы
│   ├── tests/                # Тесттер тізімі
│   ├── tests/[topic]/        # Тест беті (таймер, сұрақтар)
│   └── stats/                # Нәтижелер статистикасы
├── data/                     # careers.json, questions.json
├── public/
└── README.md
```

## Git арқылы жұмыс тәртібі

- `main`: дайын, тұрақты нұсқа.
- `dev`: даму бұтағы, бәрі осында жиналады.
- `feature/<атауы>`: әр тапсырманың жеке бұтағы (мысалы, `feature/quiz-timer`).
- Commit хабарламасы: `feat:`, `fix:`, `docs:`, `style:` префикстерімен (мысалы, `feat: add careers catalog page`).
- Өзгерісті `dev` бұтағына Pull Request арқылы қосамыз.

## Жобаны іске қосу

```bash
git clone https://github.com/AdinaSugirbai/4everr.git
cd 4everr
git checkout dev
npm install
npm run dev
```

Содан кейін браузерде http://localhost:3000 ашыңыз.
